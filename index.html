POLITIKENS PÅVERKAN PER LITER

Vilka delar kan politiken ändra?

Skatt, moms och vissa regelkostnader kan ändras genom politiska beslut. Marknadspris, valuta, frakt och företagens kommersiella beslut kan däremot inte sättas direkt av ett parti.

SÅ RÄKNAR VI

Transparens före falsk precision.

01

Pumppris inklusive moms

Du anger ett konsumentpris per liter. Det är utgångspunkten för hela fördelningen.

02

Moms räknas baklänges

Vid 25 procents moms motsvarar momsen 20 procent av ett pris som redan innehåller moms.

03

Punktskatterna dras av

Energi- och koldioxidskatt läggs in med gällande kronor per liter för vald bränsletyp.

04

Marknadsdelen särredovisas

Resten är marknads- och kedjedelen före skatt. Den delas inte upp förrän respektive kostnad kan styrkas.

Visa den matematiska modellen

Moms: pumppris − pumppris / (1 + momssats).

Marknad/kedja före skatt: pumppris / (1 + momssats) − energiskatt − koldioxidskatt.

Politiskt scenario: marknad/kedja + ändrade skatter + modellerad regelkostnad, därefter moms.

VANLIGA FRÅGOR

Vad betyder siffrorna?

Är “marknad/kedja” samma sak som oljebolagens vinst?

Nej. Den innehåller tills vidare allt före skatt som ännu inte har delats upp: produktkostnad, valuta, import, logistik, distribution, station och marginaler.

Kan ett parti bestämma pumppriset?

Nej. Politiska beslut kan direkt ändra skatt, moms och regelverk, men inte ensidigt sätta internationella produktpriser, valutakurs eller alla kommersiella kostnader.

Varför visas inget exakt partipris för vissa partier?

För att ett exakt pris kräver exakta parametrar. Om ett förslag bara anger riktning eller mål redovisas det utan att sidan hittar på ett kr/l-värde.
